## VideoPlayer:
The video player is created using finite state machine technology, using the XState library.
### Installation:
___

```sh
Clone the repository 
git clone https://github.com/DmitryBalandin/form-regisration
npm ci - installation dependencies
npm run dev - launch in browser
npm run build - project build (in folder the /dist )
```
